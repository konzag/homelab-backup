Privacy policy

Homelab backup. Last updated: 28 October 2026.

Who uses it

Homelab backup is a private tool, used only by its owner with the owner's own Google account. It is not offered to, and not used by, anyone else.

What Google data it accesses

  • Gmail, read only (scope https://www.googleapis.com/auth/gmail.readonly): messages, labels and attachments, so that a backup copy can be made. It cannot send, change or delete mail.
  • Google Drive, only its own files (scope https://www.googleapis.com/auth/drive.file): the backup files it creates. It cannot see any other file in Drive.

How the data is used

Only to make, check and restore backup copies for the owner. It is not used for advertising, not sold, not used to build profiles, and not used to develop, improve or train artificial intelligence or machine learning models.

Where the data is kept

The backup copies are encrypted and kept on the owner's own computers and in the owner's own Google Drive. The access tokens are kept only on the owner's own computers.

Sharing

The data is not shared with or transferred to anyone, and no one other than the owner reads it.

Keeping and deleting

Backup copies are kept for as long as the owner chooses, and the owner can delete them at any time. Removing the tool's access in the Google Account, under Third-party apps and services, stops all further access at once.

Google API Services User Data Policy

Homelab backup's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

This website

This website sets no cookies and uses no analytics, scripts or resources from other sites. It is hosted by GitHub Pages; GitHub may record technical data such as IP addresses, as described in the GitHub General Privacy Statement.

Changes and contact

Changes to this policy are published on this page with a new date. Questions go to the support email address shown on the tool's Google sign-in screen.
