Privacy policy

Homelab tools: Homelab backup and Family calendar. Last updated: 29 October 2026.

Who uses them

Homelab backup is used only by its owner, with the owner's own Google account.

Family calendar is used only by the owner and the owner's children, each with their own Google account. A child's account is connected by the parent, with the parent present.

Neither tool is offered to, or used by, anyone else.

What Google data they access

Homelab backup:

  • Gmail, read only (scope https://www.googleapis.com/auth/gmail.readonly): messages, labels and attachments, so that a backup copy can be made. It cannot send, change or delete mail.
  • Google Drive, only its own files (scope https://www.googleapis.com/auth/drive.file): the backup files it creates. It cannot see any other file in Drive.

Family calendar:

  • Google Calendar, only the calendars it creates (scope https://www.googleapis.com/auth/calendar.app.created): it creates one secondary calendar in the person's account and creates, changes and deletes its own events in it. It cannot see any other calendar or event.

How the data is used

Homelab backup uses the data only to make, check and restore backup copies for the owner. Family calendar uses it only to show each person's own reminders in that person's own calendar. Neither tool uses the data for advertising, sells it, uses it to build profiles, or uses it to develop, improve or train artificial intelligence or machine learning models.

Where the data is kept

Homelab backup: the backup copies are encrypted and kept on the owner's own computers and in the owner's own Google Drive; its access tokens are kept only on the owner's own computers.

Family calendar: the reminders (a short text, a date and a time) are kept in the app's database on the owner's own server, which only the family's own devices can reach; its access tokens are kept encrypted on the same server.

Sharing

The data is not shared with or transferred to anyone. No one outside the family reads it.

Keeping and deleting

Backup copies are kept for as long as the owner chooses, and the owner can delete them at any time. A reminder deleted in Family calendar is deleted from the calendar as well; the calendar it created stays in the person's account until the person deletes it. Removing a tool's access in the Google Account, under Third-party apps and services, stops all further access by that tool at once.

Google API Services User Data Policy

The use and transfer of information received from Google APIs by Homelab backup and by Family calendar adheres to the Google API Services User Data Policy, including the Limited Use requirements.

This website

This website sets no cookies and uses no analytics, scripts or resources from other sites. It is hosted by GitHub Pages; GitHub may record technical data such as IP addresses, as described in the GitHub General Privacy Statement.

Changes and contact

Changes to this policy are published on this page with a new date. Questions go to the support email address shown on each tool's Google sign-in screen.
